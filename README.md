# Roteiro de Porto Alegre

Roteiro da viagem de 31 de outubro a 2 de novembro de 2026, com programação por dia, mapa e marcação compartilhada das 13 paradas.

Abra [o roteiro publicado](https://natthanelias.github.io/poa-trip/) e compartilhe o mesmo link com o grupo. Ao tocar em **Visitado**, a marcação muda para todos os aparelhos conectados. Sem conexão, a alteração fica salva neste navegador e o envio é tentado novamente.

O aplicativo está em `index.html`, sem compilação. O GitHub Pages publica a raiz da branch `main`.

Consulte [como a sincronização funciona](docs/sync.md) para conhecer as dependências, os limites e os testes.
